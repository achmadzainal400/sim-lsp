# SIM-LSP — November 2026

Status: migrasi database SOP/Info Board diterapkan ke Supabase produksi; kode web v1.5.6; APK belum diperbarui.

## Perubahan Fase 1 — komunikasi dan identitas

- Menyederhanakan tanggapan Admin menjadi tiga langkah: verifikasi dengan alasan wajib untuk penundaan/penolakan, penugasan akun aktif terdaftar, lalu penyelesaian dengan catatan hasil dan foto wajib untuk Perbaikan. Form tindakan lengkap tetap tersedia sebagai opsi lanjutan.

- Memperlihatkan tombol ‹ dan › pada sisi kartu Info Madrasah serta memperkuat deteksi swipe pada perangkat sentuh.

- Menghapus banner SLA pada formulir laporan dan halaman SOP; informasi SLA dipusatkan di Info Board.
- Memperjelas bahwa foto bukti wajib hanya untuk laporan Perbaikan atau Pengaduan dan menghapus teks batas 512 KB dari petunjuk foto laporan.
- Menyembunyikan grup Ekspor dan paragraf panduan foto profil dari akun Warga, sambil mempertahankan fitur foto profil.

- Menambahkan profil foto per akun dengan kompresi dan tampilan avatar.
- Menambahkan komentar pada tiket dengan validasi hak akses di server untuk pelapor, Admin/Sarpras, dan pelaksana.
- Menambahkan pemberitahuan in-app per akun untuk pembaruan status, komentar, dan Info Madrasah.
- Menambahkan Info Board berbentuk kartu bertumpuk yang dikelola Admin, dengan pilihan pemberitahuan per posting.
- Mengganti banner transparansi di Dashboard dengan swipe board informasi; board juga tampil di Beranda Warga.
- Menambahkan navigasi kartu Info Board: geser, tombol sebelumnya/berikutnya, dan pergantian otomatis yang berhenti saat pengguna berinteraksi atau tab tidak aktif.
- Menambahkan katalog SOP multi-file. Warga membaca pratinjau PDF/gambar melalui viewer atau Excel sebagai tabel; file asli hanya tersedia bagi Admin.
- Menggabungkan menu SOP dan Informasi serta Info Madrasah menjadi satu menu **Informasi Madrasah** dengan tab **Pengumuman** dan **SOP & Panduan**.
- Merapikan Info Board Dashboard menjadi kartu ringkas tanpa kontrol edit/hapus; kontrol pengelolaan tetap berada di halaman Informasi Madrasah.
- Menampilkan statistik Admin sebelum Info Board, agar ringkasan utama langsung terlihat di ponsel.
- Memberi gradasi lembut per kategori, badge berkontras lebih kuat, dan batas dua baris pada judul kartu informasi.
- Memadatkan header ponsel menjadi ikon notifikasi dan avatar serta titik sinkronisasi berwarna dengan tooltip status.
- Memperjelas tampilan tombol nonaktif dan mengunci gulir latar saat drawer mobile dibuka.
- Menambahkan contoh judul pada empty state SOP; avatar kecil pada diskusi tiket sudah tersedia dan dipertahankan.
- Di Dashboard, navigasi kartu Info memakai swipe dengan titik posisi kecil pada ponsel; panah hanya tampil pada layar lebar dan tetap tersedia untuk navigasi keyboard.
- Pada Antrean di ponsel, status dan peringatan umur tiket ditata di bawah uraian dengan lebar penuh, agar rincian tiket tidak terjepit di kolom sempit.
- Untuk dokumen Word, Admin mengunggah file asli bersama pratinjau PDF. Isi katalog SOP baru dimulai kosong; data SOP lama tidak dipindahkan.
- Membatasi hak akses, jalur berkas, ukuran pratinjau Excel, serta penerima pemberitahuan di database dan fungsi server.
- Menyempurnakan susunan kartu Info dan tabel SOP untuk layar ponsel tanpa gulir horizontal pada halaman.

## Keputusan produk yang dicatat

- Excel tetap ditampilkan sebagai tabel di aplikasi.
- Warga menerima viewer pratinjau tanpa tombol unduh; konten yang sudah terlihat tetap dapat disimpan melalui fitur browser atau tangkapan layar.
- Admin menentukan per posting apakah pemberitahuan dikirim ke semua akun.
