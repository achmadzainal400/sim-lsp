# SIM-LSP — Oktober 2026

Periode arsip: 1–31 Oktober 2026

## Ringkasan

Bulan ini SIM-LSP berkembang dari aplikasi pelaporan menjadi sistem layanan sarana-prasarana dengan pengelolaan laporan, antrean, aset, akun warga, foto bukti, backup, notifikasi, analitik, dan navigasi mobile.

## Perubahan yang tercatat

### Laporan, kepercayaan, dan akses warga

- Menambahkan pembaruan status laporan dan notifikasi singkat kepada pelapor.
- Menambahkan SLA, indikator keterlambatan, konfirmasi kode tiket, serta alasan penolakan.
- Menambahkan beranda warga, pelacakan laporan milik sendiri, filter bulan dan tahun, onboarding, dan bantuan lupa kata sandi.
- Menambahkan peringatan laporan serupa tanpa memblokir pengiriman laporan.
- Menambahkan tautan pendaftaran warga dari halaman login.

### Foto laporan

- Menambahkan foto bukti hingga tiga file per laporan.
- Menambahkan kompresi foto di perangkat dan dukungan pemilihan foto dari galeri.
- Menampilkan foto pada detail tiket.
- Menyertakan metadata dan file foto dalam rancangan backup Google Drive.

### Aset dan analitik

- Menyempurnakan kelompok aset berdasarkan nama, area, tanggal pengadaan, dan status.
- Menambahkan pencarian, perubahan stok, pemindahan, impor-ekspor Excel, dan template aset.
- Menambahkan analitik dashboard: tren laporan, jenis terbanyak, rata-rata penyelesaian, dan tiket terlambat.
- Menambahkan ringkasan perubahan aset.

### Backup, notifikasi, dan cloud

- Menambahkan backup JSON dan backup Google Drive.
- Menambahkan backup foto ke Google Drive.
- Menambahkan backup otomatis malam hari dan rekap bulanan.
- Menyiapkan notifikasi push untuk laporan baru dan badge jumlah antrean di dalam aplikasi.
- Menambahkan pemantauan kapasitas penyimpanan.

### Akun dan keamanan

- Menambahkan kelola akun dengan pencarian, filter peran, dan pagination.
- Menambahkan kode aktivasi warga, termasuk pembuatan kode untuk satu warga.
- Menambahkan rancangan riwayat tindakan Admin.
- Menambahkan perbaikan akses keyboard, tautan lewati ke konten, label formulir, dan teks alternatif foto.

### Publikasi dan tampilan

- Memindahkan publikasi aplikasi ke GitHub Pages.
- Menyiapkan ikon, splash screen, PWA, dan APK.
- Menambahkan navigasi sidebar geser untuk layar ponsel pada rilis web 1.4.2.
