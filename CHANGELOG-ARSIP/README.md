# Arsip changelog bulanan

Satu file mewakili satu bulan kalender dengan nama `YYYY-MM.md`.

Arsip hanya berisi perubahan aplikasi yang dapat dibagikan: fitur, perbaikan, perubahan tampilan, dan perubahan infrastruktur yang relevan. Jangan masukkan kredensial, token, kunci rahasia, isi laporan warga, atau data pribadi.

Pada akhir setiap bulan, tinjau commit yang sudah diterbitkan, cocokkan dengan changelog yang tampil di aplikasi, lalu tambahkan file bulan tersebut ke [`CHANGELOG.md`](../CHANGELOG.md).
