# SIM-LSP Changelog

Arsip perubahan aplikasi disusun per bulan di folder [`CHANGELOG-ARSIP`](./CHANGELOG-ARSIP/).

## Cara mengarsipkan setiap akhir bulan

1. Tambahkan semua perubahan yang sudah dirilis ke file `CHANGELOG-ARSIP/YYYY-MM.md`.
2. Catat tanggal rilis, versi aplikasi, ringkasan perubahan, dan commit terkait.
3. Tambahkan tautan file bulan tersebut ke daftar arsip di bawah.
4. Jangan mencatat kata sandi, token, kunci VAPID, atau nilai rahasia lain.
